# Green Day Bank

Green Day Bank is a Java Maven GUI banking demo application.

## Project Status

This repository currently contains the full project structure scaffold, architecture docs, and implementation issue breakdown.

## Tech Stack

- Java 17
- Maven
- JavaFX
- CSV-based persistence

## Planned Features

- Sign up / login / logout by account number and password
- Savings and investment account management
- Transfers and send-money workflows
- Fund investing and withdrawals
- Transaction history and admin dashboard
- Excel export for user transactions

## Run (after implementation)

```bash
mvn clean javafx:run
```
