# Project Guide

## Purpose
This document guides contributors on how to implement Green Day Bank using the planned layered architecture.

## Contributor Workflow
1. Pick issue from `issues.md`.
2. Create/checkout feature branch.
3. Implement only the scoped files.
4. Add/adjust tests.
5. Run build and tests.
6. Open PR with linked issue.

## Suggested Module Ownership
- Core domain + services
- CSV persistence
- Security/authentication
- JavaFX GUI
- Export/admin analytics
- Testing and QA

## Done Criteria (per issue)
- Acceptance criteria met
- Tests added/updated
- No regression in existing behavior
- Docs updated when relevant
