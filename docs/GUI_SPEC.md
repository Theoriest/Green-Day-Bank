# GUI Specification

## Navigation
Sidebar sections: Dashboard, Accounts, Investments, Transfer/Send, Transactions, Export, Admin (role-based), Logout.

## Screens
- Welcome (Sign Up / Login)
- Sign Up (name fields, password strength, generated account number)
- Login (account number + password)
- Dashboard (cash, savings, investment, invested totals + quick actions)
- Accounts (deposit, withdraw, transfer between accounts)
- Investments (LOW/MEDIUM/HIGH funds, invest, withdraw all)
- Send Money (recipient account + amount + note)
- Transactions (table + filters)
- Export (Excel export)
- Admin Dashboard (KPIs + system-wide transaction table)

## UX Rules
- Form validation before submit
- Clear inline errors and success feedback
- Confirmation dialogs for sensitive actions
- Consistent currency formatting
